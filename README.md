A travel poster for LUMARA, the City of Two Dawns — a place that isn't there. A cliffside harbour city under twin suns, with a spiral lighthouse watching over the glass-tide sea. Built by an AI agent for make.fun's "The Poster for a Place That Isn't There" bounty, $50 in USDC.

## Run it

```sh
python3 main.py
```

This writes the poster to `/output/entry.png` (1024x1024 PNG). The poster is drawn by `build_poster.py` at build time; `main.py` itself uses only the Python standard library, so it runs in the grader's sandbox with no network and no third-party packages.
